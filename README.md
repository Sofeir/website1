# Сайт ASOFT

Корпоративный сайт: интерактивная продуктовая сцена на первом экране и обычная
часть сайта следом. В сцене стоят 3D-модели оборудования, собранные геометрией
по студийным рендерам из материалов бренда; сами рендеры используются в
секциях вне 3D.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5178
npm run build    # сборка в dist/
npm run preview  # просмотр собранного
npm run assets   # пересборка текстур и og-картинки из исходных SVG
```

## Что где лежит

```
public/products/        снимки оборудования и заставки экранов (генерируются)
scripts/prepare-assets  извлечение PNG из SVG, отделение фона, заставки, og
src/data/               всё содержимое сайта: продукты, тексты, цены, контакты
src/webgl/models.js     процедурные 3D-модели оборудования
src/webgl/studio.js     материалы, свет и окружение предметной съёмки
src/webgl/screens.js    изображение на дисплеях (canvas → текстура)
src/webgl/ProductStage  сцена: кейфреймы, доллинг, вращение, прокрутка
src/components/story/   интерактивная история (и её версия без движения)
src/components/sections основная часть сайта
src/pages/              главная, страницы продуктов, 404
```

## Частые правки

**Контакты и цены** — `src/data/site.js`. Телефон, почта и Telegram сейчас
заглушки (`placeholder: true`); после замены на настоящие уберите этот флаг,
чтобы исчезла подпись в подвале. Суммы в `pricing` ориентировочные и подписаны
как ориентировочные — это не прайс-лист.

**Тексты продуктов и глав истории** — `src/data/products.js`. Каждая глава задаёт
заголовок, текст и кадр: `x`, `y` — положение в долях кадра, `zoom` — насколько
близко стоит камера, `tilt` — базовый разворот. Порядок глав = порядок
повествования. Длину удержания меняют константы `WEIGHT_HOLD` и `WEIGHT_MOVE`
в `webgl/ProductStage.js`, общую длину — высота `.story` в `story.css`.

**Третий продукт** — допишите объект в `products`, соберите его модель в
`webgl/models.js` и зарегистрируйте в `BUILDERS`, а снимок и заставку экрана
получите через `npm run assets`, добавив исходник и область экрана в `SOURCES`. Сцена, витрина
решений, футер и страницы продуктов подхватят продукт без других изменений.

**Скриншоты программы.** Сейчас в разделе ПО показан макет интерфейса. Когда
появятся настоящие снимки экрана, положите их в `public/` и укажите путь в
`software.apps[].screenshot` (`src/data/content.js`) — компонент покажет
изображение вместо макета, разметку менять не нужно.

**Приём заявок.** Форма отправляет JSON (`name`, `phone`, `comment`, `page`) на
адрес из `VITE_LEAD_ENDPOINT` (см. `.env.example`). Без этой переменной работает
демонстрационный режим: заявка никуда не уходит, в консоль пишется предупреждение.

## Сцена

Оборудование в сцене — настоящие 3D-модели, собранные геометрией в
`webgl/models.js`. Читались все десять видов каждого листа: форму задают не
только фасады. Киоск — один сплошной корпус от плиты до верха с общей передней
плоскостью и ступенями назад (экран 130 мм, стойка 175 мм, блок оплаты +22 мм),
а не голова на колонне. POS стоит на тонкой ножке: 52 мм глубины под корпусом и
74 мм у плиты, почти отвесная передняя кромка и завал назад по задней
(`lofted()` — боковой профиль выдавливается по ширине с развалом). Экран
отклонён назад на 16° и вынесен вперёд от ножки. Готового .glb в материалах нет, поэтому геометрия построена по
чертёжным листам `характеристики касса.png` и
`характеристики касса самообслуживания.png`: десять ортогональных видов и
выносные размеры. Киоск — 1536 мм высоты, корпус 520 мм, глубина 420 мм, плита
12 мм, нижняя стойка 120 мм, верхний модуль 120 × 60 мм, рамка экрана 18 мм.
POS — 420 мм высоты и 230 мм глубины основания; подписи «520 мм» и «420 мм» на
его листе между собой не сходятся, поэтому ширина и пропорции стойки сняты с
силуэта рендера. Отсюда же трапециевидная стойка POS, положение модуля оплаты,
ниша терминала и сканирующий модуль в зелёной оправе. Заставка на дисплеях вырезана из тех же
снимков, поэтому экран в сцене выглядит ровно как на фотографии.

Корпус матовый чёрный — и ведёт себя как матовый чёрный. Материалы ламбертовы:
у них нет зеркальной составляющей как явления, поэтому по поверхности не может
пробежать блик. Карты окружения в сцене нет вовсе (`scene.environment` не
задаётся) — отражать нечего. Свет собран как на листах характеристик: ровная
заливка плюс два направленных источника, которые только разводят переднюю,
боковую и верхнюю грани по светлоте. При повороте на ±8° средняя яркость
корпуса меняется примерно на 2 единицы из 255 — форма читается, света «не
видно». Оборудование стоит на собственной тени: подиума под ним нет, тень
ложится на невидимую плоскость с `ShadowMaterial`.

Курсор поворачивает модель целиком в пределах ±8° по Y и ±4° по X через
затухающую интерполяцию. Прокрутка меняет положение в кадре, базовый угол и
расстояние до камеры — «приближение» делается доллингом. Геометрию не трогает
ничто: ни масштабирования, ни перекоса, ни деформации сетки.

У каждой главы два кейфрейма — приход и удержание. Вес кадра задаёт длину
отрезка после него, поэтому приход несёт вес удержания, а удержание — вес
перехода. Удержание в два с лишним раза длиннее: примерно 10 движений колеса,
за которые кадр почти неподвижен и текст читается.

Прогресс считается в `requestAnimationFrame` и пишется прямо в стиль узлов —
прокрутка не вызывает перерисовку React-дерева. `three` загружается отдельным
чанком и только когда сцена действительно нужна.

## Гамма и типографика

Почти чёрная студийная гамма: фон `#0A0B0C`, текст `#F2F4F3`. Матовый чёрный
корпус держится на таком фоне контровым светом и бликами по фаскам — так же,
как на тёмном циклораме в предметной съёмке. Зелёный остаётся брендовым: на
таком фоне `#004D40` уходит в чёрный, поэтому в акцентах и кнопках он осветлён
до `#2FBF94`. Главное действие — зелёная пилюля, а не белая плашка.

Два гротеска. Заголовки — Montserrat 800/900: плотный геометрический рисунок с
почти круглой «О», как «MODERN HOMES» в референсе (Archivo Black оттуда взять
нельзя — у него нет кириллицы). Текст — Inter 400–500, кегль от 17 px с
интерлиньяжем 1,65 и почти нулевым трекингом. Отдельной моноширинной гарнитуры
нет: технические подписи набираются тем же шрифтом в разрядку.

## Движение и доступность

При системной настройке «меньше движения» сцена не создаётся вовсе: вместо неё
показывается обычная вертикальная страница с тем же содержанием
(`StoryFallback`). Режим можно переопределить на время сессии параметром
`?motion=full` или `?motion=reduced` — это же используется для проверки обеих
версий.
